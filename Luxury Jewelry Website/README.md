# AURELIA — Luxury Jewelry Frontend

Multi-page frontend-only jewelry storefront.

## Pages
- Home
- Shop (All / Rings / Necklaces / Earrings / Bracelets)
- About
- Wishlist
- Contact

## Images
All visible photography is local AI-generated editorial imagery cropped from generated AURELIA brand visuals. No external image URLs are required.

## Run
Open `index.html` directly in a browser, or use a simple local server.

- Inner pages use clean text-only page headers; only the Home page uses a large image Hero at the top.
