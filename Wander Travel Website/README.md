# WANDER — Curated Travel Studio
Project #11 — Frontend-only travel agency website.

Features:
- English + Arabic / RTL
- Dark + Light mode
- Responsive multi-page design
- Realistic travel photography via remote image URLs
- Direct phone/email contact only
- No backend, booking engine, checkout, payment, login, registration, or online transaction flow
- Pages: Home, Journeys, Our Story, Contact


## Local AI imagery
All destination and travel visuals are stored locally in `assets/Images/` and referenced without external image URLs.
