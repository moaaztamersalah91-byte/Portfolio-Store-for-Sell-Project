# AURELIA Hotel — Frontend Portfolio Project

Luxury multi-page hotel website built with HTML, CSS and JavaScript. Frontend only; there is no online booking or backend. Guests contact the hotel directly by phone or through the contact page.

## Pages
- Home
- Rooms & Suites
- Experience
- About
- Contact

## Features
- Arabic / English with true RTL
- Dark Mode
- Responsive layout
- Hero slider
- Direct-contact booking flow (guests call the hotel or use the contact page)
- Contact form toast
- Luxury editorial design
- Local AI-generated hotel imagery
