# LUMA STUDIO — Photography Studio

Frontend-only photography studio portfolio.

- English + Arabic / RTL
- Dark / Light mode
- Responsive / mobile navigation
- Local AI-generated photographic assets included in `assets/`
- No backend, login, booking engine, checkout, payment, or database
- Contact is direct phone/email only

## Image assets
All visible photography is stored locally in `assets/` so the site does not depend on external image URLs.
