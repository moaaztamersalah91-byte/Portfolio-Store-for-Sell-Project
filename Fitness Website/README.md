# FORMA — Fitness Studio

Frontend-only fitness studio website concept.

- English / Arabic with true RTL
- Light / Dark mode
- Responsive
- Multi-page: Home, Programs, Studio, Contact
- Static program information only
- Direct phone/email contact only
- No login, register, booking engine, checkout, payments, subscriptions, dashboards, or backend

Images are loaded from Unsplash remote image URLs.


## Local imagery
All project photography is stored locally under `assets/Images/`; the former external Unsplash image references have been replaced with local WebP files.
