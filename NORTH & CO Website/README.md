# NORTH & CO. — Law Firm Website
Frontend-only portfolio project.
- Multi-page: Home, The Firm, Practice Areas, Contact
- English + Arabic RTL
- Light/Dark mode
- Responsive
- No backend, login, booking, payment, checkout, or online transaction flow
- Contact is direct phone/email only
- Visual identity: Midnight Ink + Electric Violet + Acid Lime + Soft White. Uses real photography hosted by Unsplash; internet connection is required for those photos.


### Local imagery
All website photography used by the project is stored locally in `assets/Images/` and the previous remote Unsplash image references have been replaced.
