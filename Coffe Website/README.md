# NOIRÉ — Coffee House

A premium frontend-only coffee shop website built for a portfolio.

## Included
- English + Arabic with true RTL
- Light + Dark mode
- Responsive mobile navigation
- Multi-page experience: Home, Menu, Our Story, Gallery, Contact
- Static menu filtering
- Direct phone/email contact only
- No login, signup, cart, checkout, booking, payment, newsletter, or backend flow
- Image-led visual identity with olive, sage, cream, and terracotta palette

## Run
Open `index.html` in a browser or serve the folder with any static server.


## Local imagery
All project photography is stored locally under `assets/images/`; external Unsplash image references have been replaced with local WebP files.
