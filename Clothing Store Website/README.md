# VELØURA — Luxury Fashion Store

A premium multi-page frontend concept for a fictional luxury fashion house.

## Pages
- Home
- Shop
- About
- Wishlist
- Contact

## Features
- Responsive luxury editorial UI
- Hero image slider with pagination dots and arrows
- Shop category + gender filters
- Product wishlist using localStorage
- Quick product preview modal
- Search overlay
- Mobile navigation
- Scroll reveal animations
- Image slots using remote Unsplash photography (replaceable)

## Run
Open `index.html` directly in a browser, or use any static server.

No build step is required.


## Local imagery
All project photography is stored locally under `assets/images/`; the former Unsplash image references have been replaced with local files.
