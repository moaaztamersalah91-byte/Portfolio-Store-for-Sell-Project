# MOTIF MOTORS — Curated Automotive
Frontend-only portfolio project.
- Home, Collection, Motif Studio, Contact
- English + Arabic RTL
- Dark + Light mode
- Responsive
- Direct phone/email contact only
- No backend, login, checkout, payment, booking, or online transaction flow
- Photorealistic automotive imagery is loaded from Unsplash URLs and requires internet access.
Palette: Midnight Black + Electric Lime + Cyan + Graphite.

## Image Assets
All automotive imagery used by the website is stored locally in `assets/Images/`.
The original remote Unsplash image references have been replaced with local WebP assets.
