# ATELIER — Interior Design Studio

Multi-page frontend-only interior design portfolio website.

## Pages
- index.html — Home
- about.html — About Studio
- projects.html — Projects
- project.html — Project Details
- services.html — Services + FAQ
- contact.html — Contact

## Included
- AI-generated realistic interior visuals placed throughout the site
- Emerald + Cobalt Blue + Coral visual identity
- No gold / no beige-heavy visual system
- Dark / Light mode
- English / Arabic + RTL
- Responsive layout
- Client-side project filtering
- FAQ accordion
- Frontend-only contact form demo

## Frontend-only
No backend, database, API, authentication, payments, or server-side features.
