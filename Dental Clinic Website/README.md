# IVORY — Dental Clinic

Frontend-only multi-page dental clinic website.

## Pages
- index.html
- treatments.html
- clinic.html
- contact.html

## Features
- English / Arabic with true RTL
- Light / Dark mode
- Responsive mobile navigation
- Local SVG visual assets (no fragile remote image URLs)
- Direct phone/email contact only
- No backend, login, booking system, checkout, payments, or online transactions

Open `index.html` directly in a browser.
