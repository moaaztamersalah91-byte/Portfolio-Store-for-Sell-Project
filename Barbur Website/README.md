# THE GENTLEMAN — Barber House

Frontend-only portfolio project. No backend, accounts, checkout, online booking, or database flows.

## Pages
- index.html
- services.html
- house.html
- contact.html

## Features
- English / Arabic with RTL
- Light / Dark mode
- Responsive navigation
- Direct phone/email contact only
- Static service information
- Local photography assets (no external image URLs)

## Run
Open `index.html` in a browser.
